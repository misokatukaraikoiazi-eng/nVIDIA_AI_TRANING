# NVIDIA AI Training

Welcome to the NVIDIA AI Training program for new team members. This repository contains structured training sessions to help you get up to speed with NVIDIA's AI ecosystem, tools, and best practices.

## Training Sessions

| Session | Topic | Description |
|---------|-------|-------------|
| [Session 1](sessions/session_01_intro_to_nvidia_ai.md) | Introduction to NVIDIA AI & GPU Computing | Overview of NVIDIA's AI hardware and software stack |
| [Session 2](sessions/session_02_deep_learning_fundamentals.md) | Deep Learning Fundamentals | Core concepts in neural networks and deep learning |
| [Session 3](sessions/session_03_cuda_programming_basics.md) | CUDA Programming Basics | Introduction to GPU-accelerated computing with CUDA |
| [Session 4](sessions/session_04_nvidia_ai_frameworks.md) | NVIDIA AI Frameworks | TensorRT, cuDNN, RAPIDS, and other NVIDIA tools |
| [Session 5](sessions/session_05_mlops_and_deployment.md) | MLOps and Model Deployment | Deploying AI models with NVIDIA Triton and related tools |

## Prerequisites

- Basic programming knowledge (Python recommended)
- Familiarity with Linux command line
- Access to a machine with an NVIDIA GPU (or use NVIDIA NGC cloud resources)

## Getting Started

1. Work through the sessions in order, as each builds on the previous.
2. Each session includes learning objectives, key concepts, hands-on exercises, and additional resources.
3. Estimated time per session: 2–4 hours.
